Vice Cover Studio is a little workshop for GTA 6-style poster covers: drop in up to three photos of your own (or start from the two built-in samples), pick one of four panel layouts and one of three Vice City colour grades, drag each photo into place or fine-tune it with sliders, add a title and a subtitle, then save a PNG at 1080×1080, 1080×1350 or 1920×1080. It runs entirely offline in the browser, so your photos never leave your computer, and every sunset, palm tree and letter on the cover is drawn by the app's own code — no Rockstar logos, artwork or fonts in sight.

## Run it

```sh
node serve.ts --port 8080
# open http://localhost:8080
```
